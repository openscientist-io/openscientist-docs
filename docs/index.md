# OpenScientist documentation

OpenScientist is an open-source agentic AI co-scientist for biomedical data analysis. These pages cover installation, deployment and operations. For using the app, ask the agent inside OpenScientist itself; for contributing, see the CONTRIBUTING and CLAUDE.md files in the main repository.

- Source: https://github.com/openscientist-io/openscientist
- Production: https://openscientist.io
