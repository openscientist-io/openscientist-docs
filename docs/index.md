# OpenScientist documentation

OpenScientist is an open-source agentic AI co-scientist for biomedical data analysis. These pages cover installation, deployment and operations. For using the app, ask the agent inside [OpenScientist](https://openscientist.io) itself; for contributing, see the [CONTRIBUTING](https://github.com/openscientist-io/openscientist/blob/main/CONTRIBUTING.md) and [CLAUDE.md](https://github.com/openscientist-io/openscientist/blob/main/CLAUDE.md) files in the [main repository](https://github.com/openscientist-io/openscientist).

- Source: [github.com/openscientist-io/openscientist](https://github.com/openscientist-io/openscientist)
- Production: [openscientist.io](https://openscientist.io)
- API: [REST API reference](api.md)
